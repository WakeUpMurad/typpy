# Typpy

Личный тренажёр английского по мотивам YouType: английское предложение, перевод на русский, озвучка и проверка ввода.

## Стек

- React + TypeScript + Vite.
- Material UI: кнопки, переключатель режима, поле ввода.
- Zustand: режим, тема и прогресс; прогресс сохраняется в localStorage.
- TanStack React Query: загрузка предложений и проверка ответов.
- Go: обычный `net/http`, без фреймворка, внешних зависимостей и базы данных.

## Запуск локально

Нужны Node.js 22.12+, Go 1.24+ и pnpm. На macOS Go и pnpm устанавливаются командой `brew install go pnpm`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:5173. Go API работает на порту 3000; Vite перенаправляет `/api` на него.

Для проверки собранного приложения:

```sh
pnpm build
pnpm start
```

Открыть http://127.0.0.1:3000. Один Go-сервер отдаёт и фронтенд, и API.

Если Go находится вне PATH, можно задать `GO_BIN=/путь/к/go pnpm dev`.

## Как заниматься

1. Выбрать тему и режим: с текстом, с первыми буквами или на слух.
2. Нажать «Послушать»: используется облачный голос Microsoft Edge Read Aloud, без Azure-ключа.
3. Набрать каждое английское слово в поле под ним. Пробел переводит к следующему слову, Backspace из пустого поля возвращает к предыдущему. Enter или «Проверить» проверяют всё предложение.
4. Исправить ошибку или перейти к следующему предложению.
5. Раздел «Работа над ошибками» сохраняет неверно введённые предложения. После верного ответа нажать «Дальше», чтобы убрать предложение из повторения.

Регистр, повторные пробелы и типографские кавычки нормализуются. Конечная точка скрыта и не обязательна при проверке. Слова и остальные знаки пунктуации должны совпадать. Это тренировка точного ввода исходного текста, а не оценка альтернативных переводов.

Скорость озвучки по умолчанию — 1×. Русский перевод увеличен, а интерфейс уплотнён для экрана ноутбука.

Прогресс хранится только в текущем браузере, без аккаунта и синхронизации. Для озвучки нужен доступ в интернет; приложение не использует записи Tatoeba. В режиме «На слух» английский текст скрыт, русский перевод остаётся.

## Реальные предложения: Tatoeba

Уже включены 30 пар EN/RU из Tatoeba и 108 учебных предложений. Восемь тем: повседневное общение, собеседования, работа, путешествия, встречи, знакомства, покупки и живой английский из Tatoeba. Tatoeba — корпус предложений участников, а не автоматически извлечённые цитаты из книг или фильмов. Качество перевода может различаться; импорт исключает помеченные как неподтверждённые предложения и выбирает прямые переводы.

Загрузить ещё до 30 предложений по английскому слову:

```sh
pnpm import:tatoeba travel
# или
go run ./server -import-tatoeba work
```

Импорт дополняет `server/tatoeba.json`, исключает дубликаты и сохраняет ID, автора и лицензию каждого оригинала и перевода. После импорта перезапустить Go-сервер. При публикации пересобрать Docker-образ. Практика использует локальную копию и не обращается к внешнему API.

Источники:

- [API Tatoeba](https://api.tatoeba.org/), [спецификация](https://api.tatoeba.org/openapi.json).
- [Условия использования корпуса](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus).
- Тексты: [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) или [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Ссылки и авторы отображаются под соответствующим упражнением; исходные тексты хранятся без изменений, а при отображении убирается конечная точка, что указано рядом с атрибуцией.

## Простой бэкенд

`server/main.go` содержит типы, нормализацию ответа, загрузку JSON и три маршрута:

| Метод | Маршрут        | Назначение                              |
| ----- | -------------- | --------------------------------------- |
| GET   | `/api/health`  | Проверка доступности                    |
| GET   | `/api/lessons` | Список предложений                      |
| POST  | `/api/check`   | Проверка `{ "id": 1, "answer": "..." }` |

Импорт Tatoeba отделён в `server/tatoeba.go`. JSON-файлы встроены в бинарник через `go:embed`.

```sh
pnpm lint

pnpm format:check
pnpm build
pnpm test
```

ESLint проверяет TypeScript и React Hooks, предупреждения считаются ошибками. TypeScript работает в строгом режиме, проверяет неиспользуемые переменные и параметры. Prettier отвечает за форматирование. Go-тесты проверяют API, нормализацию, некорректные запросы и фильтрацию импортируемых пар.

## Публикация

Подготовлены `Dockerfile` и `render.yaml`. Для первой публикации удобно использовать [Render Web Service](https://render.com/docs/web-services): один сервис для React и Go, публичный HTTPS-адрес, без отдельной настройки CORS.

1. Загрузить репозиторий на GitHub.
2. На Render создать Blueprint из репозитория с `render.yaml` либо Web Service с Docker runtime.
3. Выбрать подходящий тариф и выполнить deploy.

В Docker установлен `HOST=0.0.0.0`, порт берётся из `PORT`, health check — `/api/health`. Локально сервер по умолчанию доступен только на `127.0.0.1`.

Приложение пока не опубликовано. Docker-конфигурация подготовлена; для фактической публикации потребуется аккаунт хостинга. Данные прогресса остаются в браузере и после публикации.

### Edge Read Aloud без Azure

Используется библиотека [edge-tts-universal](https://github.com/travisvn/edge-tts-universal/)
(то же семейство, что `@edge-tts/universal` в JSR). Azure-аккаунт, ключ и SDK не нужны.
Прямое подключение браузерной версии сейчас поддерживается только в Microsoft Edge,
поэтому синтез выполняется небольшим Node-сервисом на 127.0.0.1:3001.
Go остаётся основным сервером и отдаёт MP3 через `/api/speech`.

`pnpm dev` запускает всё автоматически. Для собранного приложения —
`pnpm build && pnpm start`. При отдельном запуске Go также запусти `pnpm speech`.
Docker включает Node-сервис и Go; переменные Azure больше не используются.

Jenny — голос по умолчанию; доступны Guy, Aria и британский Sonia.
«Послушать» переключается на паузу и продолжение. Скорость 0.5–2× применяется
при воспроизведении, по умолчанию 1×. Смена текста/голоса останавливает звук.
Панель «Озвучить свой английский текст» принимает произвольный текст и использует
выбранные в тренажёре голос и скорость.

Минимальный API: `POST /api/speech`, JSON
`{ "text": "...", "voice": "en-US-JennyNeural" }` → `audio/mpeg`.
На Go доступна функция `TextToSpeech(ctx, text, voice) ([]byte, error)`.
Ограничение текста — 5000 байт; пустой текст и некорректные параметры дают HTTP 400.
Сервис занят — 429; ошибка подключения к Edge — 502 с сообщением.
Кеш MP3 — до 32 МБ в памяти, сбрасывается при перезапуске.

Сохранить и проиграть пример на macOS:

```sh
curl --fail-with-body http://127.0.0.1:3000/api/speech \
  -H 'Content-Type: application/json' \
  -d '{"text":"Hello! This is a test of the Microsoft English neural voice."}' \
  --output speech.mp3
afplay speech.mp3
```

В браузере (вызывать из обработчика кнопки):

```ts
async function playExample() {
  const response = await fetch('/api/speech', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      text: 'Hello! This is a test of the Microsoft English neural voice.',
      voice: 'en-US-JennyNeural',
    }),
  });
  if (!response.ok) throw new Error((await response.json()).error);
  const url = URL.createObjectURL(await response.blob());
  const audio = new Audio(url);
  audio.onended = () => URL.revokeObjectURL(url);
  audio.onerror = () => URL.revokeObjectURL(url);
  try {
    await audio.play();
  } catch (error) {
    URL.revokeObjectURL(url);
    throw error;
  }
}
```

Edge Read Aloud использует неофициальный consumer endpoint: его доступность
зависит от изменений Microsoft. Azure SDK в зависимостях отсутствует.
